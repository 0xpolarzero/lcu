# Installed-app and adapter status

Status on 2026-09-25. LCU launches a pinned official ChatGPT computer-use runtime; its thin archives do not contain OpenAI's application or copied original instruction files. Native computer use is the default. Chrome requires explicit `--chrome` setup, the official extension in the chosen profile, the original native host, and applicable site approval. The separate original `control-chrome` skill is retained as a reference; LCU exposes the original unified `cua` API.

These are local development artifacts, not published releases or a claim of complete cross-platform parity. A passed archive gate proves that archive's tested behavior; a scripted provider or direct MCP client does not establish real-model behavior in every host. Chrome site approval remains the original provider's decision, and `lcu browser status` reports configuration rather than a live connection.
