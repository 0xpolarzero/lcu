# LCU 0.8.6

This release fixes five review findings in the Linux window-targeted input translation. It adds no new harness verification claims and no new tested app pairs; Windows remains deferred.

## Changes

- **Overlays no longer receive translated pointer input.** A notification, tooltip or override-redirect popup could cover a focused GTK 4 target (activation is skipped for a focused window, the bounds check passes, and the desktop-level click follows normal pointer routing onto the overlay). Immediately before a translated click, double click, scroll, drag start or move, LCU asks the X server which mapped window is at the converted point and requires it to be the target or one of its descendants; otherwise the call fails with an error and sends nothing. The query only reads and honors input shapes. The documentation no longer says the target "is raised".
- **A hung original call can no longer block input forever.** Every call the queue makes to the original service is bounded (30 seconds). On a timeout LCU stops the trusted worker, which ends the original engine process so the call cannot act late, fails the call, and refuses queued calls without sending them; `node_repl` starts a fresh worker for the next request.
- **The X server must share LCU's PID namespace.** Before trusting an X-Resource process id, the helper checks that the server's record of the helper's own client equals its `getpid()`; otherwise it fails closed (LCU in a child PID namespace with the X server outside could previously be fooled by colliding ids).
- **An unreadable `/proc/self/ns/pid` now fails closed** instead of open.
- **Untranslated requests no longer start the X helper.** The toolkit and method are checked first, so a Qt key, a Chromium window or a hidden window pays nothing; a translated request costs one short `python3` start for the identity and one for the pointer check.
- `SYSTEM_PACKAGES` is unchanged (`libxres1` and `python3` were already required). `LCU_LINUX_INPUT_TRANSLATION=off` and the per-pair `native_input` switch are unchanged. See [Linux window-targeted input](../ADAPTERS.md#linux-window-targeted-input) and the [verification note](../verification/linux-input-translation-2026-10-02.md#086-overlays-hung-calls-namespace-proof).
